# Casualties: Unknown - русский перевод с цветными подсказками

Обновлено до 1.0.2.

Неофициальный русификатор для релизной версии Casualties: Unknown. Сделан на базе русского перевода сообщества и доработан с помощью нейросети. Его можно поставить отдельно, пока русский язык не входит в комплект игры.

## Что внутри

- Ключи и количество реплик совпадают с релизным EN.json. Файл рассчитан на базовую игру.
- Голубым выделены полезные эффекты и способы применения, жёлтым - требования и дозировки, красным - опасные состояния и предупреждения, зелёным - хорошие состояния.
- Есть три коротких подсказки про перевязку, заряд фонарика и метки для одинаковых предметов.
- Исправлены опечатки и отдельные расхождения с английским текстом. Например, обычная повязка замедляет кровотечение и помогает коже заживать.

## Установка

1. Открой [RU.json](./RU.json) и скачай его через **Download raw file**.
2. В Steam открой свойства игры и выбери **Установленные файлы - Обзор**.
3. Положи RU.json в папку CasualtiesUnknown_Data/Lang рядом с EN.json.
4. Перезапусти игру и выбери **Русский** в настройках языка.
